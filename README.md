## AWS Infrastructure Security

<div align="center">

<img src="https://github.com/user-attachments/assets/40c49bb1-6d5c-4fb3-9cc7-e7d6c7416ee3" alt="AWS Infrastructure Security" width="320"/>

</div>

In this hands-on project, I learned how to:

- Apply IAM roles and policies to control access
- Secure EC2 instances using Security Groups
- Upload and manage files in Amazon S3
- Test access restrictions using IP-based rules

The goal was simple: protect cloud infrastructure using AWS security best practices.

📖 **Blog Post**

[How to Secure AWS Infrastructure](https://dev.to/ijay/how-to-secure-aws-infrastructure-1k8h)
